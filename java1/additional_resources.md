## External study strategy

Use official documentation as the source of truth, then reinforce with books, small projects, code reviews, and timed practice. Avoid relying only on videos or question banks; Java fluency requires writing and debugging code.

## Project ideas

1. Expense tracker using files and streams.
2. URL status checker using the Java 11 HTTP client and executors.
3. JDBC-backed inventory system.
4. Annotation-based command router.
5. Concurrent metrics collector.

## Review cadence

- Same day: summarize the chapter in five bullets.
- Next day: solve two practice questions without notes.
- One week later: implement a small feature using the topic.
- One month later: revisit missed mock exam questions.
